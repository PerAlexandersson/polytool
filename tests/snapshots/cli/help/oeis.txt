List and generate recurrence-backed OEIS families.

Work with the OEIS polynomial families bundled with polytool, each generated by
an exact recurrence. `list`, `info` and `generate` use the bundled catalog;
`add`, `check` and `evidence` maintain the catalog data file in a source
checkout.

Usage: polytool oeis <COMMAND>

Commands:
  list      List the bundled recurrence-backed OEIS families.
  info      Show one bundled OEIS family and its recurrence.
  generate  Generate rows of a bundled OEIS family.
  add       Search a recurrence for OEIS rows and record it in the catalog.
  check     Re-validate catalog entries against a local OEIS copy.
  evidence  Strongest coefficient property on the first rows of each entry.

Options:
  -h, --help  Print help

Examples:
  polytool oeis list
  polytool oeis generate A008292 --count 6 --format triangle
  polytool oeis add A008292 --oeis-data ~/oeis --dry-run

Exit status:
  0  answered (also when the mathematical answer is negative)
  2  usage error or invalid input

See also:
  polytool recurrence-generate, polytool sequence, polytool help output-formats
