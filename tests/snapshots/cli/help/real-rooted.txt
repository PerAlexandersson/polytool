Check real-rootedness of each polynomial.

Decide exactly whether each input polynomial has only real roots. Coefficients
are arbitrary-size integers.

With --json, each item has a zero-based `index` (position in the input),
`degree` and `real_rooted`. The zero polynomial has degree null; constants have
degree 0.

Usage: polytool real-rooted [OPTIONS]

Options:
  -h, --help  Print help

Input and output:
      --input <FILE>     Read the input from FILE instead of stdin (`-` is stdin)
      --format <FORMAT>  Output format [default: text] [possible values: text, json]
      --json             Emit machine-readable JSON (same as --format json)

Input:
  One polynomial per line on stdin (or --input FILE): ascending integer
  coefficient lists such as `1, 3, 2`, or expanded notation such as
  `1 + 3t + 2t^2`. See `polytool help input`.

Examples:
  echo '1, 3, 2' | polytool real-rooted
  polytool sequence eulerian 6 --format rows | polytool real-rooted --json

Exit status:
  0  answered (also when the mathematical answer is negative)
  2  usage error or invalid input

See also:
  polytool properties, polytool family-check, polytool root-enclosures, polytool help input
