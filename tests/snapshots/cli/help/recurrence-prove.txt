Discover and replay general recurrence proofs.

Discover general proofs for a recurrence and seeds; no named-sequence lookup.
Tries, in the order of the parent cascade, product induction, Favard/three-term,
Liu-Wang, derivative-lag, Ma-Wang interval, Liu-Wang three-term, iterated
preserver and hypergeometric-row criteria, then the RealRooted row routes
fixed-delay window (variable_delay: f(n) P_n = A(n) P_(n-1) + B(n) x P_(n-L)
with a delay L of at least 2) and residue classes (residue_class_subsequences:
every lag a multiple of a period p of at least 2, each class P_(first + j + p m)
proved by a criterion above), the last two recorded only when the rule has their
form; every hypothesis is checked exactly for all indices. Reports every
attempt, its obligations and conclusion. A fit still needs an all-index identity
for an independently defined family. Rust certificates can be replayed; Lean
replay is not attempted.

Index-section lift (recorded only when it applies): the rows, possibly reversed,
are every p-th row (p <= 5) of a constant-coefficient parent found by factoring,
an identity for every index; the parent is proved by the criteria.

Factor gauge (recorded only when it applies): every lag-j multiplier is
kappa_j(n) q(x)^j for one fixed q, so P_n = q^(n-e) g S_n with S_n in the span
of the gauged seed rows; S_n is real-rooted for every n by its degree (<= 1), a
discriminant (degree 2 or 3) or the palindromic-quartic test (u = x + 1/x),
signs of polynomials in n decided exactly.

When no criterion proves the record:
  - tail: if one of the first rows is zero or not real-rooted, the criteria run
    on the record starting after the last such row; a proof then says "every
    row from index N on is real-rooted" (real_rooted_from_index);
  - alternative representations: the recurrence finder's menu on generated rows
    proposes other rules (first-order derivative rules with a factor f(n), lag
    at most two); a rule is used only after an all-index equality certificate
    (Ore-algebra division and invariant row annihilators, exact), then the
    criteria run on it. --max-representation-candidates bounds each finder pass
    (deterministic count; 0 disables the stage).
A rule with an inhomogeneous term matches no criterion: status not_applicable.

The recurrence input is recurrence.v1 JSON, a theorem wrapper or a
representation menu; with a menu, --candidate is required unless it has one
entry. --verify replays the recorded routes of a report from standard input
(every attempt, the tail and every equality certificate) and takes no search
flags.

Usage: polytool recurrence-prove [--recurrence <FILE|->] [--candidate N] [--max-start-delay N] [--max-representation-candidates N]
       polytool recurrence-prove --verify < proof.json

Options:
      --recurrence <FILE|->
          Read recurrence JSON from FILE (default -: stdin or --input FILE)
      --candidate <N>
          Explicit 0-based menu choice
      --max-start-delay <N>
          Induction-start retries (maximum 16) [default: 3]
      --max-representation-candidates <N>
          Finder configurations per alternative-representation pass (0: off) [default: 300]
      --verify
          Replay the recorded routes of a report from stdin; no search flags
  -h, --help
          Print help

Input and output:
      --input <FILE>     Read the input from FILE instead of stdin (`-` is stdin)
      --format <FORMAT>  Output format [default: text] [possible values: text, json]
      --json             Emit machine-readable JSON (same as --format json)

Input:
  A JSON document on stdin (or --input FILE), described on this page.

Details:
  JSON output is polytool.recurrence-proof-discovery.v1. Its trivially_real_rooted
  is true when the supplied (not fitted) rule is B(n) P_n = A(x,n) P_(n-k) and
  product induction proves it. real_rooted_from_index is the first index N with
  every row P_n, n >= N, proved nonzero and real-rooted. A residue-class proof may
  leave whole residue classes of zero rows (conclusion.zero_residue_classes,
  residues of n modulo the period); real_rooted_from_index is then omitted and
  real_rooted_outside_zero_residue_classes gives from_index and the zero classes
  (status proved). tail and alternative_representations hold the later stages,
  each alternative with its polytool.recurrence-equality.v1 certificate. Reports
  saved before a criterion was added still replay (attempts are additive).

Examples:
  polytool recurrence --json < rows.txt | polytool recurrence-prove --recurrence - --json
  polytool recurrence-prove --recurrence rec.json --json > proof.json
    polytool recurrence-prove --verify < proof.json

Exit status:
  0  proved (or the replayed certificate is valid)
  1  not proved
  2  usage error, invalid input or a failed replay

See also:
  polytool recurrence-degree, polytool recurrence-theorems, polytool help recurrence-json
