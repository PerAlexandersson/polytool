Chen--Fu--Ruan left production matrix: TNN triangle, PF rows.

Read rows P_0, ..., P_N with deg P_n = n (a lower-triangular matrix A with
nonzero diagonal, a_{n,k} = [t^k] P_n), compute exactly the leading block Q_N of
its left production matrix Q = A (1 ⊕ A^{-1}), that is

  a_{n,0} = q_{n,0},  a_{n,k} = sum_{i=k..n} q_{n,i} a_{i-1,k-1},

and decide whether Q_N is totally nonnegative (TNN). By Chen--Fu--Ruan
(arXiv:2512.08369) a TNN Q_N certifies, for the supplied rows: every row is a
Polya frequency sequence (real-rooted, nonpositive zeros), and A_N and its
reversal [a_{n,n-k}] are TNN. On success the certificate is re-verified: A_N is
regenerated from Q_N, Q_N is checked TNN, and for every row n the
unified-network window M_{n,n}[n..2n; 0..n] is compared with the transposed
Toeplitz section of P_n (Theorem 4). An explicit planar network for Q_N is
printed: Q_N = L D with L the canonical network Gamma_N(lambda) and D the
diagonal of Q_N. On failure an explicit negative minor of Q_N is given when
found.

By default the input is P_1, P_2, ... with P_0 = 1 prepended.

Usage: polytool left-production [OPTIONS]

Options:
      --first-index <0|1>  Index of the first input row (1: P_0 = 1 is prepended) [default: 1]
  -h, --help               Print help

Input and output:
      --input <FILE>     Read the input from FILE instead of stdin (`-` is stdin)
      --format <FORMAT>  Output format [default: text] [possible values: text, json]
      --json             Emit machine-readable JSON (same as --format json)

Input:
  One polynomial per line on stdin (or --input FILE): ascending integer
  coefficient lists such as `1, 3, 2`, or expanded notation such as
  `1 + 3t + 2t^2`. See `polytool help input`.

Details:
  Guardrails:

    The criterion is sufficient, not necessary: if Q_N is not TNN nothing follows
    about the rows (the Eulerian rows are real-rooted, but q_{4,2} = -5). A
    certificate covers only the supplied rows. Covered families include exponential
    Riordan arrays R[f', f] with f' PF (Stirling numbers of both kinds, Lah numbers),
    r-Whitney numbers, and Brenti's n-recursive triangles with nonnegative
    coefficients (Pascal, Delannoy).

  JSON output has the schema polytool.left-production.v1.

Examples:
  printf '0,1\n0,1,1\n0,1,3,1\n0,1,7,6,1\n' | polytool left-production
  printf '1,1\n1,4,1\n1,11,11,1\n1,26,66,26,1\n' | polytool left-production --json

Exit status:
  0  Q_N is TNN and the certificate re-verifies (rows certified PF)
  1  not certified
  2  invalid input or options (for example deg P_n != n)

Deprecated spellings (still accepted; they print a warning on stderr):
  --first-row -> --first-index

See also:
  polytool pf-network, polytool tnn-network, polytool brenti-recognize
