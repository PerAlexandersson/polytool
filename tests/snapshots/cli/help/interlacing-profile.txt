Count consecutive previous interlacings until first fail.

For each row, count how many consecutive previous rows it interlaces with,
walking backwards until the first failure. With --json the report includes the
checked previous-pair reports. Coefficients are arbitrary-size integers.

Usage: polytool interlacing-profile [OPTIONS]

Options:
  -h, --help  Print help

Input and output:
      --input <FILE>     Read the input from FILE instead of stdin (`-` is stdin)
      --format <FORMAT>  Output format [default: text] [possible values: text, json]
      --json             Emit machine-readable JSON (same as --format json)

Input:
  One polynomial per line on stdin (or --input FILE): ascending integer
  coefficient lists such as `1, 3, 2`, or expanded notation such as
  `1 + 3t + 2t^2`. See `polytool help input`.

Examples:
  printf '1\n1,1\n1,2,1\n' | polytool interlacing-profile

Exit status:
  0  answered (also when the mathematical answer is negative)
  2  usage error or invalid input

See also:
  polytool interlacing, polytool family-check
