Expand palindromic polynomials in the gamma basis.

Expand each palindromic input polynomial in the gamma basis t^i (1+t)^(d-2i),
where d is the degree. A polynomial that is not palindromic has no such
expansion and is reported as an error. Coefficients are arbitrary-size integers.

Usage: polytool gamma-expansion [OPTIONS]

Options:
  -h, --help  Print help

Input and output:
      --input <FILE>     Read the input from FILE instead of stdin (`-` is stdin)
      --format <FORMAT>  Output format [default: text] [possible values: text, json]
      --json             Emit machine-readable JSON (same as --format json)

Input:
  One polynomial per line on stdin (or --input FILE): ascending integer
  coefficient lists such as `1, 3, 2`, or expanded notation such as
  `1 + 3t + 2t^2`. See `polytool help input`.

Examples:
  echo '1, 11, 11, 1' | polytool gamma-expansion
  polytool sequence eulerian 6 --format rows | polytool gamma --json

Exit status:
  0  every row has a gamma expansion
  1  some row is not palindromic
  2  usage error or invalid input

See also:
  polytool properties, polytool help coefficient-order
