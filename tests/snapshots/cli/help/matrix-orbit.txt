Certify stationary interlacing-matrix orbits exactly.

Read a JSON object with recurrence (a recurrence.v1 record with seeds) and
optional state_system. Without a state system, search companion forms of orders
1..4 and threshold and separated-characteristic shapes of orders 1..3, with
constant/affine state seeds solved exactly. A supplied state system has matrix
(square ascending rational-string polynomial entries), start_vector (ascending
rational-string polynomials) and projection (constant rational-string weights),
dimension 1..5 and entry/seed degrees at most 24. The certified transformed
matrix must have degree at most one. Check the scalar recurrence as a matrix
polynomial identity and every prescribed seed, all positive-parameter Branden
pencils, an ordered nonnegative interlacing seed, nonnegative transformed
projection weights, and exact nonvanishing. The conclusion is nonzero
real-rooted projected rows for every index; no consecutive interlacing or
simplicity is asserted. Failure means no certificate within the bounds.

Usage: polytool matrix-orbit [OPTIONS]

Options:
      --verify  Replay a saved matrix-orbit report from input
  -h, --help    Print help

Input and output:
      --compact          Print compact (single-line) JSON
      --input <FILE>     Read the input from FILE instead of stdin (`-` is stdin)
      --format <FORMAT>  Output format [default: json] [possible values: json]
      --json             Emit JSON (the default; accepted for uniformity)

Input:
  A JSON document on stdin (or --input FILE), described on this page.

Details:
  JSON schema polytool.matrix-orbit.v1. Search tries every state ordering and
  nonnegative unit triangular bases: elementary shears with coefficients 1/2, 1, 2
  and 0/1 triangular patterns (at most two off-diagonal entries in dimension 5),
  with at most 4096 basis candidates per request. Shape parameters are a in
  {0,1,2}, b in {0,-1,-2}; thresholds range from 0 to the state dimension, with
  markers 0, 1, 1+x. The defining recurrence must be stationary, homogeneous,
  without derivatives, order <=8 with <=32 seeds. Certificates replay exact
  rational pencil, basis, identity and support data. Rust replay is not Lean
  replay.

Examples:
  polytool matrix-orbit --input request.json > certificate.json
  polytool matrix-orbit --verify --input certificate.json

Exit status:
  0  proved or replay verified
  1  no proof within the search bounds
  2  invalid input or certificate

See also:
  polytool recurrence-prove, polytool interlacing
